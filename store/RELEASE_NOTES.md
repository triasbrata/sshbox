# Jeansh: release notes

## 1.0: first release

**Terminal buddy in your pocket.**

### Highlights

- **Sessions in tabs:** several per host, with native tmux split panes and
  Duplicate session on a long press.
- **Keys for a touch screen:**
  - a key bar with Ctrl, Alt, Esc, Tab and the arrows, which you can reorder
    and trim;
  - the magic key, two rings of keys under your thumb;
  - arrow keys from a long press on blank space.
- **Files:**
  - a VS Code-style tree for each server, with uploads into any folder and
    downloads to the phone;
  - a code editor with syntax colours, find and replace, go to line, drafts
    and sudo save;
  - Markdown opens rendered.
- **Connections:**
  - passwords or private keys, and jump hosts;
  - port forwarding in both directions, with ready-made ports for common
    databases;
  - Tailscale SSH, and servers you start put on your tailnet.
- **Looks:** light and dark themes (Dracula, Nord, Gruvbox, Solarized,
  Catppuccin, Tokyo Night, One Dark) and five terminal fonts.
- **Security:**
  - host keys are checked before they're trusted, and Known hosts lists them;
  - secrets are encrypted with the Android Keystore;
  - none of the app's data goes into Google backups.

### Notes

- For Android 7.0 or newer (minSdk 24), phones and tablets.
- No account, no ads, no analytics.
