# Jeansh: catatan rilis

## 1.0.0: rilis pertama

**Teman terminal di saku Anda.**

### Sorotan

- **Sesi dalam tab:** beberapa per host, dengan panel split tmux asli dan
  Duplicate session lewat tekan lama.
- **Tombol untuk layar sentuh:**
  - bilah tombol berisi Ctrl, Alt, Esc, Tab, dan panah, yang urutan dan
    isinya bisa diatur;
  - magic key, dua cincin tombol di bawah jempol Anda;
  - tombol panah lewat tekan lama di area kosong.
- **File:**
  - pohon file ala VS Code untuk setiap server, dengan unggah ke folder mana
    pun dan unduh ke ponsel;
  - editor kode dengan warna sintaks, cari dan ganti, lompat ke baris, draf,
    dan simpan dengan sudo;
  - file Markdown tampil ter-render.
- **Koneksi:**
  - kata sandi atau private key, dan jump host;
  - port forwarding dua arah, dengan port siap pakai untuk database umum;
  - Tailscale SSH, dan server yang Anda jalankan bisa masuk ke tailnet Anda.
- **Tampilan:** tema terang dan gelap (Dracula, Nord, Gruvbox, Solarized,
  Catppuccin, Tokyo Night, One Dark) dan lima font terminal.
- **Keamanan:**
  - host key diperiksa sebelum dipercaya, dan Known hosts menampilkannya;
  - rahasia dienkripsi dengan Android Keystore;
  - tidak ada data aplikasi yang ikut ke cadangan Google.

### Catatan

- Untuk Android 7.0 atau lebih baru (minSdk 24), ponsel dan tablet.
- Tanpa akun, tanpa iklan, tanpa analitik.
